쀼가계부

테스트에 참여해 주셔서 고맙습니다 🙏

준비 Play 스토어로 설치 파일로 설치 처음 사용 의견 보내기 안 될 때

1. 시작하기 전에

  • 안드로이드 휴대폰만 됩니다. (아이폰은 아직 준비 중이에요)
  • Play 스토어에서 쓰는 구글 계정(Gmail 주소)을 운영자에게 알려 주세요. 이 주소로만 테스트 앱이 보여요.
  • 운영자가 어떤 방법으로 설치할지 알려 드려요. 보통은 2번(Play 스토어)이고, 스토어 준비 전에는 3번(파일)이에요.

2. Play 스토어로 설치 보통 이 방법

  1. 운영자에게 알려 준 구글 계정으로 로그인한 휴대폰에서 아래 버튼을 눌러요. ① 테스트 참여하기
  2. 열린 화면에서 "테스터 되기"(Become a tester)를 눌러요.
  3. "테스터가 되었습니다"가 나오면 아래 버튼으로 Play 스토어를 열고 설치를 눌러요. ② Play 스토어에서 설치
⏰ 14일 동안 지우지 말아 주세요. 구글 규칙상 테스터 12명이 14일 이상 계속 참여해야 정식 출시를 할 수 있어요. 매일 쓰지 않아도 괜찮지만, 가끔 열어서 써 주시면 큰 도움이 돼요.

"찾을 수 없음"이 나오면 아직 운영자가 테스트를 열지 않았거나, 다른 구글 계정으로 로그인되어 있는 거예요. Play 스토어 오른쪽 위 프로필에서 계정을 확인해 주세요. 참여 후 스토어에 뜨기까지 몇 시간 걸릴 수도 있어요.

3. 파일(APK)로 설치 스토어 준비 전

  1. 운영자가 카카오톡 등으로 보낸 app-release.apk 파일을 눌러 받아요.
  2. 받은 파일을 누르면 "출처를 알 수 없는 앱" 안내가 나와요 → 설정 → 지금 쓰는 앱(카카오톡·내 파일 등)의 "이 출처 허용"을 켜고 뒤로 가기.
  3. 설치를 눌러요.
  4. "Play 프로텍트" 경고가 나오면 세부정보 더보기 → 무시하고 설치를 눌러요. 스토어를 거치지 않은 앱이라 나오는 안내예요.
🔁 나중에 Play 스토어 테스트가 시작되면 이 앱을 먼저 지우고 2번 방법으로 다시 설치해 주세요. (파일로 깐 앱과 스토어 앱은 서명이 달라서 위에 덮어 설치가 안 돼요.) 가계부 내용은 서버에 있어서, 같은 계정으로 다시 로그인하면 그대로 보여요.

4. 처음 사용하기

로그인

  • 구글 또는 카카오로 로그인하면 가장 쉬워요.
  • 이메일로 가입하면 확인 메일이 와요. 메일의 링크를 누르면 "인증 완료"가 나오고, 앱에서 로그인하면 돼요. 메일이 안 보이면 스팸함도 봐 주세요.

가계부 만들기 · 배우자 연결

  • 처음 로그인하면 "가계부 만들기"를 눌러요.
  • 배우자(또는 같이 테스트하는 분)와 함께 쓰려면: 한 사람이 ⚙ → 설정 → 배우자 초대에서 6자리 코드를 만들고, 다른 사람은 가계부를 만들기 전에 "초대 코드 입력"에 그 코드를 넣어요.
  • 혼자 테스트해도 괜찮아요.

써 보면 좋은 것

  • 아래 + 버튼으로 지출·수입 입력 (공동 / 개인 구분)
  • 예산 탭에서 이번 달 예산 정하기
  • 통계 탭에서 카테고리별·월별 지출 보기
  • 경조사 탭에서 축의금·부조금 기록
  • ⚙ → 설정 → 결제 알림 자동 인식(선택): 카드·은행 앱 알림을 읽어 "새 결제"로 모아 줘요. 알림 내용은 휴대폰 안에만 저장되고, 내가 [추가]를 눌러야 가계부에 들어가요.

5. 의견 보내기

불편한 점, 이상한 점, 있었으면 하는 기능 모두 좋아요. 화면 캡처가 있으면 더 좋아요.

  • 앱 안: ⚙ → 설정 → 문의하기
  • 메일: help@alkongmochi.com
  • 또는 운영자에게 카카오톡으로 편하게 보내 주세요.

6. 안 될 때

"테스터 되기" 화면이 안 열려요

운영자에게 알려 준 구글 계정과 휴대폰·브라우저에 로그인된 계정이 같은지 확인해 주세요. 크롬에서 열면 잘 돼요.

쀼가계부가 두 개 깔렸어요

예전에 받은 테스트 앱이 남아 있는 거예요. 둘 다 지우고 2번 방법으로 다시 설치해 주세요.

가입 확인 메일이 안 와요

스팸함을 확인하고, 5분이 지나도 없으면 다시 가입하거나 구글·카카오 로그인을 써 주세요.

계정·데이터를 지우고 싶어요

⚙ → 설정 맨 아래 회원 탈퇴를 누르면 바로 지워져요. 자세한 내용은 개인정보처리방침에 있어요.
